# 🃏 Blackjack Web Game

An interactive, fast-paced Blackjack game built with modern JavaScript and Vite. Players can challenge the computer dealer, track scores in real time, and enjoy a dynamic card-dealing visual experience.

## ✨ Technologies

- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## 🚀 Features

- Dynamic deck generation and deck shuffling logic using standard 52-card sets.
- Real-time score calculation with instant win/loss condition evaluation.
- Responsive dealer (computer) AI that draws cards based on player totals.
- Clean layout with interactive animations for card dealing.
- **Hidden Easter Egg:** Includes a secret interaction/trigger for curious players to discover.

## 📍 The Process

I wanted to practice core JavaScript logic, DOM manipulation, and module bundling without relying on heavy frontend frameworks. Building a Blackjack game was the perfect challenge to sharpen my knowledge on array methods, event handling, and game state management. 

I focused on keeping the user interface simple yet intuitive, making sure cards are dealt dynamically and scores update seamlessly. Setting it up with Vite allowed me to keep the project light, modular, and fast!

## 🚦 Running the Project

1. Clone the repository:
   git clone https://github.com/ArmandoJimenez-dev/blackjack-js.git
2. Install dependencies:
   npm install
3. Run development server:
   npm run dev
4. Open http://localhost:5173 in your browser.
